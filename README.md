# CampusConnect – College Event Portal

## 🌐 Live Demo

🚀 **College Event Portal:**  
https://pandillapujitha.github.io/College---Event---portal/

A simple, responsive college event website built with only HTML, CSS and JavaScript. No backend, no database.

## Files
- `index.html` – Home page with hero section
- `events.html` – Event cards with category filter
- `register.html` – Registration form with success message
- `gallery.html` – Photo gallery with popup viewer
- `contact.html` – Contact details and message form
- `style.css` – All styling (change colors at the top in `:root`)
- `script.js` – Menu, filters, form checks, lightbox
- `images/` – SVG images (replace with your own photos if you like)

## Run locally
Double-click `index.html` to open it in your browser.

## Deploy on GitHub Pages
1. Create a new repository on GitHub and upload all files (keep `index.html` in the root).
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Using your own photos
Put your images in `images/`, then change the file names in the `<img src="...">` lines in `events.html`, `gallery.html` and `index.html`.
